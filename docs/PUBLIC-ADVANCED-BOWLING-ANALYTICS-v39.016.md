# Public Popz Bowling Stats v39.016 — Advanced Ball, Line, Lane and Transition Analytics

**Approved scope:** Owner requested that the commercial public PWA's Advanced Shot Tracking become useful for decisions about balls, lines, lanes and changing conditions, adopting proven ideas from **Personal Bowling v49.9–v49.10**. This is a PUBLIC-app-only release and does not modify Personal Bowling, its 8787 server, LAN master, scoring history or backups.

**Public baseline:** public-v39.015, Cloudflare Pages `popzbowling.com` with $9.99 one-time Lifetime Pro, 30-day full-Pro trial, permanent owner-approved Founders, account-bound Google Sync and Free local scoring/history. The Pro upgrade has **no new charge**, and trial, Lifetime and Founder users all receive the new Pro panels. Stripe live credentials/price, Firebase security rules and billing-review monitoring are unchanged.

## New Pro scoring and analysis

1. With **Settings → Advanced Shot Tracking** enabled and active Pro access, enter a lane pair, e.g. 21-22. The current game then displays independent **Stand Board / Target Board** values for Lane 21 and Lane 22. Select **Game Starts on Lane** before recording the first roll. The active physical lane alternates by frame, highlights the next lane, and a new game starts on the opposite lane while retaining both profiles. Ball remains selected separately. The first roll of each frame snapshots Ball/Stand/Target **plus actual physical lane**, which is not rewritten when later board settings change. Undo of the frame's first roll clears that frame's snapshot and physical lane. Single-lane/legacy input paths remain usable. Phone lane entry remains in the existing **Game details & actions** drawer; tablet uses the existing Full Layout.
2. **Mixed-ball statistics correction:** historical games with frame-level tracking no longer get credited as a full game for the originally selected ball if later frames used a different ball. A ball earns a full-game score/average only when all ten tracked first balls used that ball. Earlier untracked games retain their original game-level ball association (no fictional frame positions). Pro's **By Ball — First-Ball Results** and **Ball & Line Results** show actual tracked-frame strike percentage, first-ball pinfall, full-game attribution, sample counts, stand/target boards, physical lanes, oil and center context. Core Free By Ball remains a conservative complete-game summary.
3. **Lane Transition Analysis:** Detect intended feet/target/ball changes and compare actual observed strike percentage, first-ball pinfall and explicitly recorded ten-pin leaves before/after. Alternating physical lanes are analyzed **separately** so ordinary lane alternation is not misclassified as a move. Sample-evidence stages are Early, Building, Useful and Strong, using the tested Personal Bowling thresholds; avoid claiming small samples prove a change. Recent events can be expanded in the Stats panel.
4. **Bowling Performance Evaluations:** Recalculate compact overall, ball/line, lane-transition, leave and recent-form comments from saved scores and current filters. **Deterministic, offline and no external AI or API charges**. Pro analysis of Team scores requires choosing a single bowler, to prevent advice based on conflating different players' physical lines.

These three premium sections are collapsed by default and use the existing persistent Stats panel controls, so the tablet presentation, phone keypad, scoring sequence and bowling History remain unchanged. An expired trial immediately hides Pro analytics and shows a clear Pro lock while retaining scores, board snapshots, Free stats and JSON backup/import. New physical-lane fields are additive and validated in backups; Google Sync carries them as part of existing per-session documents. **No customer data migration, deletion or reset.**
