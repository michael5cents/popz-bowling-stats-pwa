# Popz Bowling Stats Public v39.011 — Whole-Number Averages and Handicap

Release date: October 21, 2026
Production: https://popzbowling.com
Source: michael5cents/popz-bowling-stats-pwa (GitHub and Gitea, main)

## Request and result
Display bowling averages like an official league: **drop the fractional portion rather than rounding**. Use the whole-number bowling average **as the base for the handicap calculation**, before applying the handicap percentage. For example, an average of 180.8 is shown and treated as 180, making handicap 36 pins/game at 90% of 220 rather than 35.

## Scope
- Shared scoring engine `scoring.mjs`: central `wholeBowlingAverage()` helper; handicap floors average before applying percentage. Carry-book seed averages also use the whole-number official seed.
- `app.js`: overall Stats, league book/latest/next-week, per-date and per-league averages, performance breakdowns, History, setup suggestions, single/team end-of-series reports, editable entering-average fields, handicap formula, and save confirmations use whole numbers. New and edited entering averages are saved as whole numbers.
- `index.html`: entering-average fields have integer step; team roster input does too.
- `live/viewer.mjs`: read-only spectator final average displays a whole number, keeping percentage rates precise. Live API data shape and privacy allowlist are unchanged.
- `public-v39.011`: app bundle, manifest, service-worker/cache URLs, and update checks are updated together.

## Compatibility and safety
- Bowling pinfall, original game data, strike/spare/leave percentages, and precision needed for statistical calculations are unchanged.
- Existing decimal entering-average values from older local/Google backups are displayed as whole numbers and floored for handicap, without destructive data migrations.
- Offline scoring, service-worker update recovery, Pro Preview, Google Sync, live sharing, and required anonymous telemetry retain existing behavior.
- Personal Bowling (`bowling-stats-offline`) is a separate app and is not modified.
