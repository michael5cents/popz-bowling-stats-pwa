## Purpose

Address the seven reliability issues identified in the November 1 public-app review before further beta expansion. This release focuses on completed-history sync, team scoring corrections, backup safety, reliable offline startup, trustworthy health reporting, coordinated updates, and missing entering averages.

## Changes

1. **Firestore-safe completed history.** Omit undefined object properties from outgoing copies, including nested optional fields, while preserving arrays and leaving the local bowling record unchanged. New single-bowler series omit unused team linkage fields. This prevents omitted optional fields from rejecting an otherwise valid completed-series upload. The new top-level Undo action history is device-local and excluded from cloud state; existing telemetry-marker behavior is unchanged.
2. **Team Undo follows the latest roll.** Persist a device-local action history for the active single/team game. Undo restores the bowler/game associated with the latest recorded roll across automatic turn rotation or manual selection, supports repeated Undo, and survives reload. Frame edits, game creation/deletion, series start/finish, and successful backup imports establish an explicit Undo boundary. Pre-v39.012 team rolls have no reliable global action order and use the existing bowler/frame editor; legacy single-bowler Undo remains supported.
3. **Validate backups before changing saved data.** Check the complete backup and its supported session/game/frame/settings structure before merge or persistence. Reject an invalid import as a whole; preserve the existing non-destructive merge and active-series protections for valid backups.
4. **Protect the cached offline startup page.** Refresh the app-shell cache only from app-shell navigation. Keep dashboard/login routes, live spectator routes, and API responses outside the scoring app's navigation cache so an online visit cannot replace the offline app entry point.
5. **Report runtime query failures honestly.** A failed diagnostic query must make the health result unhealthy/unavailable rather than look like a successful query with zero errors. External monitoring continues to use that result to identify dependency failures.
6. **Advance all release signals together.** Use public-v39.012 across the client, manifest, service worker/cache, version file, and versioned resources so installed devices can receive the corrected implementation.
7. **Skip missing carry-book seeds.** Do not convert null, blank, or missing entering averages to zero when selecting the book-average seed. Continue looking for a valid saved entering average and preserve whole-number handicap behavior.

## Compatibility

- The public app remains an installed, offline-first PWA at popzbowling.com.
- Existing local scores, history, backups, and Google Sync data are preserved. Valid imports still merge; active series remain protected.
- Pro Preview, Quick/Detailed Scoring, Team scoring, live sharing, and the Free scoring/history/backup baseline retain their existing scope.
- Anonymous adoption telemetry and runtime diagnostics remain separate from bowling history. Owner dashboard data remains owner-only.
- The personal app `bowling-stats-offline` is separate and is not part of this release.
- The intentional existing MacBook edit to `tools/launch-qa-phone.sh` is outside this release and must be preserved.
